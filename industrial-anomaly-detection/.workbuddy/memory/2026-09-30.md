# 2026-09-30 工作日志

## F_alpha PatchCore Mini Experiment — 第一阶段

### 研究假设
在工业异常检测中，随 style/illumination-sensitive feature 抑制增强（alpha↑），不同 defect type 性能变化规律可能不同。

### 核心设计（已验证技术可行）
- F = PatchCore concat 后的 multi-scale embedding，shape (B, 1536, 32, 32)（wide_resnet50_2，layer2+layer3，输入 256×256）。
- F_IN = InstanceNorm(F)（affine=False，逐样本逐通道在空间维归一化）。
- F_alpha = (1-alpha)*F + alpha*F_IN。
- **IN 插入位置**：覆写 `PatchcoreModel.generate_embedding`，在 concat 后、reshape 前对 embedding 做 `F.instance_norm`。alpha=0 时跳过 IN，与原版 PatchCore bit-wise 一致（已数值验证）。
- train/test 走同一 forward，transform 天然一致；阈值由 PostProcessor 自适应，不受 scale 影响。

### 关键实现要点
- `FAlphaPatchcoreModel(PatchcoreModel)`：覆写 `generate_embedding`。
- `FAlphaPatchcore(Patchcore)`：覆写 `__init__` 替换 torch 模型 + `configure_evaluator` 增加 image/pixel AUPR(AP)。
- 固定随机种子（KCenterGreedy 用 torch.randint + SparseRandomProjection 含随机投影，必须 seed）。

### 环境坑（重要）
1. **Engine 不能用 `device=` 参数**（Trainer 不接受），用默认自动检测 GPU。
2. **必须用 `barebones=True`** 关闭 Anomalib 自动添加的 ModelCheckpoint（否则 checkpoint 序列化在系统 RAM 紧张时 OOM）。`enable_checkpointing=False` 会与自动 ModelCheckpoint 冲突报 MisconfigurationException。
3. **GPU 显存争用**：RTX 5060 Laptop 8GB 被 Chrome/ChatGPT/微信等图形应用占用 ~3GB，全量 209 图 coreset 峰值约 2.6GB 处于边缘，会**间歇性 OOM**。已加 `limit_train` 参数（`LimitedMVTecAD` + `_LimitedDataset` 透传 collate_fn）作为内存受限回退；正式实验建议关闭图形应用。

### 交付文件
- `experiments/falpha_patchcore.py`：模型 + run_experiment + CLI（参数化，可批量跑不同 alpha）。
- `scripts/smoke_test.py`：最小 smoke test（F_alpha 数值校验 + bottle alpha=0/1）。
- `results/falpha_experiment/bottle/alpha_{0,1}/metrics.json` + `predictions.jsonl`（83 条/alpha，含 defect_type/gt_label/anomaly_score）。

### smoke test 结果（全量 209 训练图，seed=0）
- alpha=0：image_AUROC=1.0，pixel_AUROC=0.9856，pixel_F1=0.727
- alpha=1：image_AUROC=1.0，pixel_AUROC=0.9822，pixel_F1=0.714

## 第二阶段：alpha=0 vs alpha=1 paired 分析（只分析已有结果，未训练）

- `scripts/analyze_falpha.py`：读两个 predictions.jsonl → 配对检查 → delta 统计 → Wilcoxon → 图表 + CSV。
- 输出在 `results/falpha_experiment/bottle/analysis/`：paired_scores.csv（83 行全量配对）、stats_summary.json、fig1_mean_score / fig2_delta_boxplot / fig3_paired_slope.png。
- 配对性：83↔83 完全一一对应，defect_type/gt_label 无不一致，无缺失 score。数量：broken_large=20, broken_small=22, contamination=21, good=20。
- 核心发现（探索性，单类别单种子）：
  - broken_large 显著下降（median Δ=-0.076，80% 图片下降，Wilcoxon p=0.0015，r=-0.83）
  - broken_small 轻度上升（median Δ=+0.023，p=0.048，r=+0.50）
  - contamination 上升（median Δ=+0.046，p=0.022，r=+0.60）
  - good 基本不变（median Δ=+0.006，p=0.37）
- 方向与朴素假设相反：结构缺陷(broken_large)最敏感且下降，细微/表面缺陷上升。注意 anomaly_score 是 per-run min-max 归一化后的值，magnitude 受归一化影响，方向（rank-based）更可靠；IN 的 scale 混淆因素仍未排除。

## 第三阶段（新方向）：MVTec AD 2 illumination shift — Phase 0 数据/前提验证（未训练）

- 新实验目录 `experiments/mvtec_ad2_illumination_sensitivity/`（含 README.md + 官方 code utils 存 reference/）。
- 旧 F_alpha 标为 Preliminary/Deprecated：`experiments/falpha_patchcore_README.md`。
- **MVTec AD 2 关键事实**（官方论文 arXiv:2503.21622 + 官方 code utils 确认）：
  - 8 类：can/fabric/fruit_jelly/rice/sheet_metal/vial/wallplugs/walnuts，总量 ~30.4GB，CC BY-NC-SA 4.0。
  - 结构：train/good、validation/good、test_public/{good,bad}+ground_truth/bad、test_private、test_private_mixed。
  - 光照 shift = 真实采集（曝光± + 类别特定光源：反射/梯度/色温），每类≥4 种，**非统一连续光强**。
  - 光照分离：test_private（常规）↔ test_private_mixed（变化，**同场景配对**），但两者**均无公开 GT**。
  - 公开 GT 仅 test_public，但只分 good/bad（**无缺陷类型、无光照标注**）。
- **核心结论（Phase 0 Decision = MODIFY）**：「defect-level illumination sensitivity」无法用公开数据本地验证——光照分离数据无 GT、公开 GT 数据无缺陷类型/光照标签。候选改法见 README §12。
