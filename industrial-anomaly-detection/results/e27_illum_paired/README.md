# E27 · 真实光照下的同工件配对得分变化（事后探索性）

**日期**：2026-10-30
**论文阶段**：投稿前最后一轮补充 — 光照相关证据的准确表述
**要验证的核心论断**：R1 是否降低了**同一工件在不同真实光照下**的得分波动。
**性质**：**post-hoc exploratory**，仅用已有 F0/R1 逐图得分，不训练、不推理、不新增 GPU。

## 1. 数据与口径

| 项 | 值 |

## 3. 异常情况

- 正常工件剔除数：10 类分别为 32/30/26/30/27/29/20/23/25/26 个可用（其余因光照不全被剔除，
  逐 cell 计数见 `illum_sd_category.csv` 的 `n_specimens_excluded` / `exclude_reasons`）。
- Motor 的 3-seed 间 Δ 的 sd（0.00609）明显大于其他类别（0.0004–0.0029），该类别对种子最敏感。

## 4. 分析

**事实**：R1 使正常工件跨真实光照的得分样本标准差在 10/10 类别下降，宏平均 −0.0080（CI 不含 0）；
同期 9/10 类别 AUROC 上升（Doll 例外）。

**解释（必须限定）**：正常与异常得分的均值**同时下移**（−0.042 至 −0.174），正常与异常 SD **同时收缩**
（异常侧收缩幅度在 7/10 类别与正常侧相当）。因此这是**整体压缩**，不能直接解读为"R1 专门消除了光照引起的漂移"。
可支持的说法是"R1 降低了同工件跨光照的得分离散度"，**不足以**支撑"消除了特征漂移"或"证明了因果机制"。

**与主结论的关系**：E22 主表 ΔAUROC +0.0076 [−0.0014, +0.0164] 区间跨零；本分析给出的是一致方向上的**机制侧证据**，
不改变主结论的统计强度。

**假设（未验证）**：Doll 的"波动下降但排序退化"可能与它的分数整体下移幅度最大（−0.0818）叠加异常侧压缩不足有关；
本轮不做缺陷类型分层，不作机制归因。

## 5. 结论

光照相关证据已补齐到可准确表述的程度：**可以说"跨光照得分波动系统性下降（10/10 类，宏平均 −0.0080，CI 不含 0）；
其中 9/10 类同时观察到排序改善，Doll 为例外"**；**不能说**"消除了光照漂移"、"改善固定阈值性能"、"因果机制"。

## 6. 出口条件判断

- 若主指标方向不一致或区间跨零 → 该证据只能作描述。**未发生**（10/10 同向，CI 不含 0）。
- 但主指标是**离散度**而非判别性能 → 必须与 AUROC/AP 并列陈述，不得替代。
