# E27 · 真实光照下的同工件配对得分变化（事后探索性分析）

日期：2026-10-30
性质：**仅使用已有 F0/R1 逐图得分**（`results/e22/cells/*.json`），不训练、不推理、不新增 GPU 实验。
定位：**post-hoc exploratory**，不得推翻或替代主实验结论。

---

## 1. 预先固定的分析口径（结果产生前写定）

| 项 | 设定 |
|---|---|
| 数据 | M²AD 10 类 × view120 × seed{0,1,2} |
| 主分析对象 | **正常测试工件**（`image_anomaly==0`）在真实 10 个光照下的观测 |
| 有效图像 | F0 与 R1 使用**完全相同**的图像集合（`detectable != False` 过滤后，两者天然同一集合） |
| 覆盖要求 | 优先使用 10 个光照齐全的工件（`n_illum == 10`）；不足者**剔除并报告数量与原因** |
| 唯一主要指标 | 每个工件跨光照得分的**样本标准差**（`ddof=1`） |
| 聚合顺序 | 类别内工件等权 → 3 seed 平均 → 10 类等权 |
| 差值 | R1 − F0（同工件、同光照集合） |
| 区间 | 工件级配对 bootstrap；3 seed 共用同一次工件抽样；3000 次；2.5/97.5 百分位 |
| 类别呈现 | **10 类全部列出**，不只展示改善类别 |

## 2. 防误读的配套检查

1. 正常与异常得分的**均值/标准差变化**，样本口径与主评价一致（`detectable != False`）。
2. 异常工件的覆盖统计：多少异常工件在过滤后有 10 个光照（`anomaly_illum_coverage.csv`），仅作描述性汇总。
3. 把跨光照 SD 变化与 AUROC/AP 变化并列（`illum_vs_ranking.csv`），显式检查
   "跨光照变化减小但排序退化" 的类别。
4. 不新增多重检验；只报告一个主要指标与上述描述性检查。

## 3. 禁止的表述

- 不得称"消除了特征漂移"、"证明了因果机制"、"改善固定阈值性能"；
- 不得把 SD 下降直接解释为 AUROC 提升的原因（本分析无因果识别）；
- 不得因某个类别方向不一致而删除该类别。
