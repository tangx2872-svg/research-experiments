# 工件级 bootstrap：旧版 vs 修正版（引用规则）

**日期**：2026-10-23
**旧版**：`results/paper_supplement_20261023/audit_a3_specimen_cluster_bootstrap.json`
**新版**：`results/paper_final_pack_20261023/specimen_bootstrap_v2.json`
**两者输入相同**（`results/e22/cells/*.json` 的 `scores_f0/scores_r1/labels/specimen/detectable_raw`），**方法不同**。

---

## 1. 方法差异（这是"差异来源"的唯一原因）

| 项 | 旧版 | 修正版 |
|---|---|---|
| 三种子如何合并 | 每个 seed **独立**跑 3000 次；再对三个 seed 的**分位数取平均** | 每次 replicate 内**先算每 seed 的 Δ，再对 3 seed 取平均**；分位数在合并分布上取 |
| 区间含义 | "三个 seed 各自 95% 区间端点的平均" —— **不是任何统计量的 95% 区间** | "三种子平均 ΔAUROC 的 95% 区间" |
| 随机流 | 每 seed 用 `rng_seed + seed`（**不同抽样**） | 同一类别内 3 seed **共用同一次工件抽样** |
| 点估计 | bootstrap 均值的平均 | **原始样本**（未重采样） |
| 图像身份对齐 | 直接假定数组顺序一致 | 按 `(specimen, illumination, kind)` **身份对齐**后再算 |
| 宏平均 | 无 | 10 类 / 开发 3 类 / 扩展 7 类，**在 replicate 内先平均类别** |
| 退化重采样 | 记录 | 记录（本次 **0 次**） |
| 权重实现 | 逐次拼接索引 | 整数 `sample_weight`，并与"显式复制"对比验证（max|Δ| = 0.0） |

## 3. 结论与引用规则

1. **结论方向未变**：两版都显示"多数类别区间跨 0、Doll 方向为负、Ring 相对最稳"。
2. **唯一实质变化**：Ring 的区间在新版下**排除 0**；Doll 的 P(Δ>0) 从 0.101 变 0.074 —— 属方法修正后的正常移动，**不得**解释为"结果变强/变弱"。
3. **论文只引用修正版**；旧版保留为过程记录，若在内部文档出现，必须标注"区间构造有缺陷，勿引用"。
4. **估计对象始终是**：固定 3 个 seed 下、测试工件抽样不确定性；**不是**训练随机性，**不是**跨类别总体泛化，**不是** p 值。
