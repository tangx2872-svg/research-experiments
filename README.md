## 2026-09～10｜教学与科研协作平台

在 Django LMS 基础上完成教学流程与轻量科研协作升级。界面采用苏州工学院主题，校训为「立本求真，日新致远」。

主要完成：
- 跑通教师发布作业 → 学生提交 → 教师评分 → 学生查看成绩流程
- 完善课程、作业、评分和权限逻辑
- 完成自动化测试和数据库迁移
- 增加科研项目、成员角色、任务关联和不可覆盖的进度提交
- 保留成果文件版本、历史下载、讨论和项目动态
- 提供无需登录的只读访客演示：2 个示例项目、10 项任务、11 次进度
- 实验提交历史、ZIP 代码浏览与左右版本对比、报告预览、材料清单和按项评分
- 课程小组实验、组员个人调整分、批改筛选、批量下载与成绩导出
- 77 项测试通过，完成独立演示环境的浏览器流程验证

**主要收获：**
熟悉开源 Web 项目的部署与扩展，在复用账号和附件机制的基础上实现项目权限、历史追溯、增量迁移及回归验证。

运行、演示、功能与验证：[教学与科研协作平台](2026/09/django-lms/README.md)
